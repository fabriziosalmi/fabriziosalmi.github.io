# fabriziosalmi.github.io

Landing page and **canonical privacy notice** for the open-source project sites
published under `fabriziosalmi.github.io`.

Every project site on this host is static, served by GitHub Pages, sets no
cookies and runs no analytics — so instead of duplicating a privacy notice in
dozens of repositories (where copies inevitably drift apart), they all link to
one document:

**https://fabriziosalmi.github.io/privacy**

If the notice needs updating, change it **here** and every project site is
updated at once.

| File | Purpose |
|---|---|
| `privacy.html` | Canonical privacy & legal notice (EN + IT) |
| `index.html` | Minimal landing page for the host root |
